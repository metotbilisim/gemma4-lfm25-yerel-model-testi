    *   *Standard approach for nested transactions:* Maintain a stack of "undo" logs or "delta" maps.
    *   *The "Undo Log" approach:*
        *   When `Set(k, v)` is called:
            *   If in a transaction, record the *previous* state of `k` (either the old value or a "not exists" marker).
            *   Update the main store.
        *   When `Delete(k)` is called:
            *   If in a transaction, record the *previous* value of `k`.
            *   Remove from main store.
        *   When `Rollback()` is called:
            *   Pop the top of the transaction stack.
            *   Iterate through the recorded changes and restore the previous state.
        *   When `Commit()` is called:
            *   Clear the transaction stack.

         - `oldValue == null`: `mainStore.Remove("a")`.
         - `oldValue != null` is false.
    Result: `mainStore` empty, `valueCounts` empty. Correct.

    *Wait, one more: `Set` then `Set` same value:*
    1. `Set("a", "1")`
       - `mainStore: {"a": "1"}`
       - `valueCounts: {"1": 1}`
       - `stack: [ [("a", null)] ]`
    2. `Set("a", "1")`
       - `oldValue = "1"`
       - `stack.Peek().Add(("a", "1"))`
       - `valueCounts["1"]--` (0)
       - `mainStore["a"] = "1"`
       - `valueCounts["1"]++` (1)
       - `stack: [ [("a", null), ("a", "1")] ]`
    3. `Rollback()`
       - `i=1`: `change = ("a", "1")`. `currentValue = "1"`.
         - `currentValue != null`: `valueCounts["1"]--` (0).
         - `oldValue ("1") != null`: `mainStore["a"] = "1"`.
         - `oldValue ("1") != null`: `valueCounts["1"]++` (1).
       - `i=0`: `change = ("a", null)`. `currentValue = "1"`.
         - `currentValue != null`: `valueCounts["1"]--` (0).
         - `oldValue == null`: `mainStore.Remove("a")`.
    Result: `mainStore` empty, `valueCounts` empty. Correct.

    *Final check on `Commit`*:
    If I call `Commit()`, it just clears the stack. The `mainStore` and `valueCounts` are already updated. This is $O(1)$ (or $O(\text{depth})$). This is the most efficient way.
